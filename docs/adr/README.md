# Architecture Decision Records

One file per decision, named `NNNN-short-title.md`, where `NNNN` is a zero-padded sequence.

Suggested template:
```
# NNNN — <title>

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
## Alternatives considered
```
